# calender
Calendar with Event Reminders
### This is a responsive, and interactive calendar web app that allows users to:
1. View a monthly calendar
2. Select any date
3. Add, edit, or delete event reminders
4. Navigate through months
5. Automatically highlight today's date
6. Store all events using localStorage

.
├── index.html        # Main calendar layout and modal
├── style.css         # Calendar styles, modal, animations
└── script.js         # Calendar logic, event handling, and localStorage
